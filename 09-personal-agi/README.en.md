# Personal AGI

[中文](README.md) · **English**

## Working thesis

A personal model should maintain a **persistent, uncertainty-aware, and revisable state** about a user. It must distinguish durable preference from temporary intent, observed behavior from underlying goals, and useful memory from information that is merely available.

## Questions

- How can multiple or conflicting intents coexist without being averaged away?
- When should memory be updated, compressed, forgotten, or challenged?
- How can personalization remain controllable and legible to the user?
- What evaluation horizon reveals genuine adaptation rather than short-term mimicry?
