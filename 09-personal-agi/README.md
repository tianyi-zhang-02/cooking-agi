# Personal AGI：一个真正“认识你”的模型需要什么？

**中文** · [English](README.en.md)

## 先用一句话讲清楚

Personal AGI 不是一个知道你姓名的聊天机器人，而是一个能在长期交互中形成理解、承认不确定、接受纠正，并逐渐学会怎样帮助你的系统。

## 一个最简单的例子

你对模型说：“帮我安排下个月的旅行。”

普通助手可能只处理当前这句话。Personal AGI 还应该知道：

- 你更喜欢自然景观还是城市打卡；
- 你上次因为行程太满而感到疲惫；
- 这次是和朋友还是家人同行；
- 哪些只是过去偏好，哪些仍然有效；
- 哪些信息不确定，应该先问你。

真正的价值不是“记得更多”，而是**在正确的时候使用正确的理解**。

## 它和普通个性化有什么区别

传统个性化经常做的是：根据历史行为，预测用户下一次最可能点击什么。

Personal AGI 想进一步处理：

- 用户当前想完成什么任务；
- 长期目标和短期意图怎样共存；
- 模型怎样跨任务迁移对用户的理解；
- 用户怎样查看、修改或删除模型形成的状态；
- 系统怎样知道自己对用户的判断可能错了。

所以它不只是 recommender，也不只是 memory。它需要一套完整闭环。

## 六个必要部分

### 1. 用户状态

保存目标、偏好、知识、限制和当前情境，但要带上时间、证据与置信度。

### 2. 长期记忆

知道什么值得保留、何时取出、怎样更新，以及什么时候应该忘记。

### 3. Search 与工具

能够寻找最新信息、个人文件和外部证据，而不是只依赖模型参数。

### 4. 推理与行动

把用户状态、当前任务和外部证据组合起来，决定回答、追问还是执行工具。

### 5. 反馈与学习

从纠正、偏好和真实结果中学习，但不能把所有观察行为都当成真实意图。

### 6. 用户控制

让用户知道系统记住了什么、为什么这样判断，并能纠正或撤回。

## 最难的几个问题

### 用户不是一个固定向量

一个人可以同时有多个兴趣和角色，并且会随时间变化。把全部历史压成一个平均表示，很容易让小众但重要的意图消失。

### 行为不等于目标

用户点了什么，受到曝光、界面和时间影响。系统需要区分“用户选择了它”和“用户只被给了这个选择”。

### 越个性化不一定越好

如果模型一直迎合已知偏好，体验可能越来越窄。好的 Personal AGI 应该知道何时利用熟悉信息，何时提供新选择。

### 长期关系需要不同评估

一次回答很难证明模型真的理解用户。更重要的是它是否减少重复沟通、能否吸收纠正，以及几周后是否仍然有帮助。
