# AI collaborator marks

- Claude Code uses the Claude starburst from [Simple Icons 16.33.0](https://github.com/simple-icons/simple-icons/blob/16.33.0/icons/claude.svg), with its original geometry. Simple Icons is distributed under CC0; trademark rights remain with the brand owner.
- Codex uses the existing OpenAI Blossom asset at `../company-icons/openai.svg` to identify its provider, not a separate Codex product logo. Its provenance is documented in `../company-icons/SOURCES.md` and `site/company-icons.json`.

These marks identify the AI tools acknowledged by this project, not company sponsorship or endorsement. They are served locally and run through the same 72-pixel Floyd–Steinberg dithering as human avatars, over a shaded disc. The resulting canvas uses only black and white. This presentation is a site treatment, not a new official logo. Names and roles remain readable separately in the credits and table, including without JavaScript.
