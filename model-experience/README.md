# Model Experience

**中文** · [English](README.en.md)

## 当前理解

模型质量是用户在一段交互轨迹中感受到的结果，而不是某一次回答的分数。好的 Model Experience 同时包含 usefulness、relevance、breadth、control、校准后的置信度，以及跨多次交互的持续改善。

## 我关心的问题

- 哪些离线指标能够预测用户真正感受到的变化？
- 怎样评估跨 session 的改善，而不是孤立 turn 的质量？
- 个性化何时会变成视野收窄或过拟合？
- 模型怎样表达不确定性并主动邀请用户纠正？
