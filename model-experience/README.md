# Model Experience

## Working thesis

Model quality is experienced as a trajectory, not a single response. A strong model experience combines usefulness, relevance, breadth, control, calibrated confidence, and improvement across repeated interactions.

## Questions

- Which offline metrics predict the experience a user actually notices?
- How do we measure improvement over sessions rather than isolated turns?
- When does personalization become narrowing or overfitting?
- How should models communicate uncertainty and invite correction?
