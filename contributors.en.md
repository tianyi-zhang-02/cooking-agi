# Contributor universe

[中文](contributors.md) · **English**

> Reading time: ~2 min · Type: community · Last reviewed: 2026-09

There is no author’s chair here—only people who moved the notes forward. Some wrote a whole series; others fixed one typo. Both count as real momentum in this universe.

The crew below is generated from Git history. GitHub contributors drift through orbit with their avatars and usernames; AI collaborators appear from commit trailers rather than being quietly erased.
