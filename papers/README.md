# 论文

**中文** · [English](README.en.md)

这里放读论文时的笔记。除了整理方法和结果，我也会记下没看懂的地方，以及哪些结论还需要再验证。读的时候主要看这几个问题：

1. **作者想解决什么，提出了什么结论？** 先试着用自己的话概括。
2. **实验能支持这个结论吗？** 看 baseline、实验条件和消融，而不只看最后的分数。
3. **这个结论有什么限制？** 换一批数据或换一个场景，还能成立吗？可以怎么验证？
4. **有什么值得借鉴？** 哪个方法可以试试，哪些问题值得继续研究？

带着这些问题，再去看公式、实现细节，以及方法依赖的假设。
