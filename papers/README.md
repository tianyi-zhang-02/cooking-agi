# 论文

**中文** · [English](README.en.md)

一篇一篇地读。这里不写「这篇论文讲了什么」——那是 abstract 的活儿。每篇精读回答的是同一组问题：

1. **它到底 claim 了什么？** 一句话说清楚；说不清楚，多半是自己还没读懂。
2. **证据撑得住吗？** 实验测的是那句 claim，还是一个更容易的问题。
3. **什么结果会推翻它？** 说不出来的话，这个 claim 本身就有毛病。
4. **对手上的东西意味着什么？** 看完之后我改不改自己的做法。

之后才轮到细节：机制、假设、它在整个系统里的位置。
