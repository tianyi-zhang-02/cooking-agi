## 一个问题可以讲到什么程度

比如“为什么 attention 要除以 $\sqrt{d_k}$？”

- **先讲直觉**：点积的数值尺度如果随维度增大，softmax 就容易变得很尖。
- **再讲前提**：在分量独立、零均值、单位方差等简化假设下，点积的方差为 $d_k$；除以 $\sqrt{d_k}$ 后，方差回到 1。
- **最后讲限制**：真实模型中的 Q、K 未必满足这些假设。这是在解释缩放的动机，不是在保证训练时的方差永远为 1。

需要完整计算过程，读[多头注意力](../../00-foundations/core/multi-head-attention.md)。想验证自己会不会实现，去 [ML Coding](../../learn/ml-exercises/README.md)。同一个概念，理解、表达和实现可以分别练。

## 复习到哪里先停

能解释机制，能举一个小例子，也能说出结论的前提，就可以继续下一题。被追问卡住时，记下具体缺口，例如“不会推方差”或“不懂 mask 的方向”，比写一个“attention 不熟”更方便回头补。

这不是标准答案库。不同岗位会关注不同深度；公式不必每次全部展开，但自己应该知道省略了哪些步骤。回到[面试准备](../README.md)可以换到代码或算法路线。
