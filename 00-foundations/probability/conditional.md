## 条件概率：把世界缩小到 A

**定义**（这是定义，不是定理）：当 $P(A) > 0$，

$$P(B \mid A) = \frac{P(A \cap B)}{P(A)}$$

直觉是这样的：知道 A 发生了，就把 A 外面的结果全部扔掉，A 成了新的样本空间。B 在这个缩小的世界里还剩下的部分是 $A \cap B$，再除以 $P(A)$，让新世界的总概率回到 1。

## 链式法则：永远成立

把定义挪一下：

$$P(A \cap B) = P(A)\,P(B \mid A)$$

这条**永远成立**，不需要任何假设。事件相关的时候照样可以乘，只是乘的是条件概率。

拿下雨和下雪说：$P(\text{下雨且下雪}) = P(\text{下雨}) \cdot P(\text{下雪} \mid \text{下雨})$。如果下雨的日子更容易下雪，这个数就比 $P(\text{下雨}) \cdot P(\text{下雪})$ 大。

## 独立：条件概率塌缩成普通概率

**定义**：$P(A \cap B) = P(A)\,P(B)$。它和 $P(B \mid A) = P(B)$ 是同一句话的两种写法：

- 如果 $P(A \cap B) = P(A)P(B)$，代进条件概率的定义，$P(B \mid A) = P(A)P(B) / P(A) = P(B)$；
- 反过来，$P(B \mid A) = P(B)$ 两边乘上 $P(A)$，就回到 $P(A \cap B) = P(A)P(B)$。

对称地也有 $P(A \mid B) = P(A)$。所以独立只是链式法则的一个特例：条件概率恰好等于普通概率。

有一点常被说错：**「能同时发生」不等于独立。** 下雨和下雪可以同一天发生，但它们几乎肯定相关——都是同一个天气系统推出来的。有交集是独立的必要条件，不是充分条件。独立是一条要算出来验证的等式，不是「感觉这两件事没关系」。实际题目里，独立通常来自问题的设定：两枚不同的硬币、两个不同的日子，而不是看集合长什么样。

## 互斥不是独立

这是概率面试里最常见的一个错。

| | 互斥（disjoint） | 独立（independent） |
| --- | --- | --- |
| 说的是 | 集合：$A \cap B = \varnothing$ | 概率：$P(A \cap B) = P(A)P(B)$ |
| 意思 | A 发生了，B 就不可能 | 知道 A 发生，对 B 没有任何信息 |
| 配哪条法则 | 加法：$P(A \cup B) = P(A) + P(B)$ | 乘法：$P(A \cap B) = P(A)P(B)$ |

关键事实：**两个概率都大于 0 的互斥事件，一定不独立。** 互斥说 $P(A \cap B) = 0$，独立要求 $P(A \cap B) = P(A)P(B) > 0$，两者矛盾。互斥其实是最极端的相关：看到 A，你就知道 B 不可能。

掷一颗骰子，三个例子：

- $A = \{1, 2\}$，$B = \{5, 6\}$：互斥。$P(B \mid A) = 0$，可 $P(B) = 1/3$，不独立。
- $A = \text{偶数} = \{2, 4, 6\}$，$B = \text{不超过 4} = \{1, 2, 3, 4\}$：有交集。$P(A) = 1/2$，$P(B) = 2/3$，$P(A \cap B) = P(\{2, 4\}) = 1/3 = 1/2 \times 2/3$，独立。这纯属数字上的巧合，所以永远要把 $P(A \cap B)$ 算一遍。
- A 和 $A^c$：互斥。除非 $P(A)$ 是 0 或 1，否则不独立。

## 全概率公式

按 A 发生与否分两种情况，各自乘上权重再相加：

$$P(B) = P(B \mid A)\,P(A) + P(B \mid A^c)\,P(A^c)$$

不知道 A 的结果、又想算 B 的时候，就用它。

## 两两独立不等于相互独立

掷两枚均匀硬币：A = 第一枚正面，B = 第二枚正面，C = 两枚一样。

- $P(A) = P(B) = P(C) = 1/2$；
- $P(A \cap B) = P(A \cap C) = P(B \cap C) = 1/4$，所以三对都独立；
- 但 $P(A \cap B \cap C) = P(\{HH\}) = 1/4 \ne 1/8 = P(A)P(B)P(C)$，三个一起**不**相互独立。

原因是知道其中任意两个，第三个就定下来了。这是「两两独立但不相互独立」的经典例子，面试里常出。

## 面试常见问题

<details class="interview" markdown="1">
<summary>掷两枚硬币，A = 第一枚正面，B = 第二枚正面，C = 两枚一样。A 和 B 互斥吗？独立吗？A 和 C 呢？</summary>

A 和 B 不互斥（HH 两个都满足），独立：$P(A \cap B) = 1/4 = 1/2 \times 1/2$。A 和 C 也不互斥，$A \cap C = \{HH\}$，$P(A \cap C) = 1/4 = P(A)P(C)$，同样独立。三个放一起见上面：两两独立，但不相互独立。

</details>

<details class="interview" markdown="1">
<summary>不放回地抽两张牌，A = 第一张是 A，B = 第二张是 A。求 P(A ∩ B)、P(B)，A 和 B 独立吗？放回呢？</summary>

不放回：链式法则，$P(A \cap B) = \frac{4}{52} \cdot \frac{3}{51} = \frac{1}{221}$。全概率，$P(B) = \frac{3}{51} \cdot \frac{4}{52} + \frac{4}{51} \cdot \frac{48}{52} = \frac{1}{13}$。而 $P(A)P(B) = \frac{1}{169} \ne \frac{1}{221}$，不独立。

意外的是 $P(B) = 1/13$，和第一张一模一样：不知道第一张是什么的时候，第二张和第一张是对称的。

放回：$P(A \cap B) = \frac{1}{169}$，$P(B) = \frac{1}{13}$，独立。

</details>

<details class="interview" markdown="1">
<summary>互斥和独立有什么区别？两个互斥事件能独立吗？</summary>

互斥说的是集合：$A \cap B = \varnothing$，配加法；独立说的是概率：$P(A \cap B) = P(A)P(B)$，配乘法。两个概率都为正的互斥事件一定不独立——互斥让 $P(A \cap B) = 0$，独立要求它等于一个正数。

</details>

<details class="interview" markdown="1">
<summary>为什么 P(A ∩ B) = P(A)P(B) 和 P(B | A) = P(B) 是一回事？</summary>

用条件概率的定义 $P(B \mid A) = P(A \cap B) / P(A)$：前者代进去得到后者；后者两边乘 $P(A)$ 得到前者（需要 $P(A) > 0$）。

</details>
