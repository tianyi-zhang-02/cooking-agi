# 解题方法：不靠灵光一现，也能找到入口

**中文** · [English](README.en.md) · [复习总览](../README.md)

> 阅读时间：约 8 分钟 · 逻辑、计数与证明方法 · 最近审阅：2026-10

有些题看上去像脑筋急转弯，其实是在问：你能不能把不重要的故事拿掉，找到一个不会变的量，或者一个必须发生的冲突。这里不整理谜底，整理能带到下一题的方法。

## 1 · 先缩小问题，不是先猜答案

遇到一般 n，先算 n=1、2、3；遇到复杂操作，先写出一次操作前后哪些量变了。小例子有 2 个用途：发现规律、推翻错误猜想。它不能替代对所有 n 的证明。

比如“每次同时翻转两枚硬币”。正面数可变 −2、0、2，**奇偶性不变**。全反面出发，不可能到达奇数个正面的状态。无需穷举所有操作顺序。

## 2 · 抽屉原理：把“总会撞上”讲严谨

N 个对象进入 m 个箱子，至少一个箱子有 $\lceil N/m\rceil$ 个对象。否则所有箱子都少于这个下界，总数不够。

例子：任取 n+1 个整数，至少两个除以 n 的余数相同，二者之差可被 n 整除。关键不在计算大整数，而在只有 n 个余数类别。

<details markdown="1">
<summary>再走一步：任意 n 个整数，存在一段非空连续子序列，其和可被 n 整除</summary>

看前缀和 $S_1,\dots,S_n$ 的余数。如果某个为 0，从头到那里就行；否则 n 个前缀和挤进 n−1 个非零余数，两个相同。它们相减对应中间一段。也可把 $S_0=0$ 一起加入，直接对 n+1 个前缀和用抽屉原理。

</details>

## 3 · 归纳法：重点是怎么从 n 走到 n+1

想证 $\sum_{j=1}^n j=n(n+1)/2$。基础步 n=1；假设对 n 成立，加上 n+1 得 $(n+1)(n+2)/2$。

若下一步依赖所有更小规模，用**强归纳法**。例如每个大于 1 的整数都能分解成素数乘积：若它是素数就结束；否则拆成两个严格更小且大于 1 的因子，对它们用归纳假设。这证明存在性，不自动证明分解唯一。

## 4 · 反证、逆否、极端元素，不是一回事

| 方法 | 做什么 | 适合哪里 |
| --- | --- | --- |
| 逆否命题 | 证非 Q 推出非 P，代替 P 推出 Q | 原结论不容易直接操纵 |
| 反证法 | 假设结论不成立，推出矛盾 | 不可能性、无理数、唯一性 |
| 极端元素 | 选最大、最小、最短，再看它必须满足什么 | 有限结构与递减过程 |

<details markdown="1">
<summary>例子：为什么 √2 不是有理数？</summary>

假设 $\sqrt2=a/b$，其中 a,b 为互质正整数。则 $a^2=2b^2$，a² 偶数意味着 a 偶数，写 a=2c，得到 b²=2c²，因此 b 也偶数，与互质矛盾。别漏掉“先约成最简分数”。

</details>

## 5 · 配对、双计数、递推：同一批对象换着看

配对求和把首尾凑成常数。双计数则用两种方法数同一个集合：

$$
\sum_{k=0}^n k\binom nk=n2^{n-1},\qquad n\ge1.
$$

左边先选 k 人小组，再选组长；右边先从 n 人中选组长，其余 n−1 人各自决定来不来。不是两个式子刚好相等，而是两个式子都在数“带组长的小组”。

若题目逐步增加规模，写递推并检查初值。例如长度 n 的二进制串不含连续 1，按最后一位分类：以 0 结尾有 $a_{n-1}$ 种，以 1 结尾前一位必须 0，有 $a_{n-2}$ 种。因此 $a_n=a_{n-1}+a_{n-2}$，$a_0=1,a_1=2$。

## 6 · 信息下界：知道不可能，比瞎试有用

每次测试最多区分 b 个结果，k 次自适应测试最多有 $b^k$ 个结果叶子。要唯一识别 N 个等先验候选，至少需要 $\lceil\log_bN\rceil$ 次。

这是**必要下界，不保证可实现**：实际允许的测试可能无法把候选均匀分开。天平题有 3 种结果，但“重还是轻未知”和能否使用标准砝码都会改变状态空间与可行测试。

## 7 · 对抗和最坏情况：先让对方选

最小化最坏损失与最大化平均收益不同。前者要写 $\min_{\text{strategy}}\max_{\text{outcome}}L$，后者需要一个概率分布。没有给分布，就别把每种情况默认等可能。

讲解时按“模型 → 不变量或分类 → 证明 → 边界”走。不必把每题都包装成很聪明的 trick。
