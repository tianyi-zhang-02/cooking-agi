# 求职：到底要准备什么

**中文** · [English](prepare.en.md)

> 阅读时间：约 4 分钟 · 最近审阅：2026-09

先说结论：**别什么都准备，但也别什么都不准备。**

这两句听着矛盾，其实是一件事。什么都准备，是把 LeetCode、系统设计、八股、论文、项目全摊开，每样摸一点，
结果每样都不扎实，人还累垮了。什么都不准备，是觉得"我做过就会讲"，真到面试上讲不出个所以然。

中间那条路是：**先想清楚你要什么，再决定准备什么。**

## 一、先想清楚要什么

这一步跳过去，后面全是无用功。几个问题，答案不用很确定，但心里得有个方向：

- 我想做哪一类活？（建模 / 数据 / 基础设施 / 产品侧）
- 我在哪儿？签证、地点、家里的情况，这些是真实约束，不丢人。
- 我愿意为什么加班？为什么不愿意？
- 三年以后我希望自己会什么？

不同方向要的人真的很不一样。同样叫 MLE，有的岗位天天写 SQL 和特征，有的天天调训练，
有的大部分时间在修 pipeline。你投之前不分清楚，面试的时候就会被问出来。

我自己的看法写在[这里](../career/not-binary.md)：找工作只是人生的一部分，不是一道是非题。

## 二、三条线，按重要性排

### 1. 你的故事（最重要，也最被低估）

简历上每一条，你都要能讲三分钟：**当时什么问题、你具体做了什么、结果怎么样、你从中学到什么。**
最后那句是分水岭——大部分人只讲前三句。

几个容易翻车的地方：

- **说不清自己的贡献。** "我们团队做了 X"——那你做了什么？
- **没有数。** 提升了多少、省了多少、多快，能量化就量化；量化不了就说清楚为什么。
- **不敢讲失败。** 讲一个真失败过的项目，讲你怎么判断、后来怎么改，比十个顺利的项目有说服力。
- **技术细节答不下去。** 你写在简历上的每个词——某个模型、某个框架——都可能被追着问三层。

### 2. 基本功

这部分有现成的：[LeetCode 怎么刷](../interview/leetcode.md)、[系统设计](../interview/system-design.md)、
[技术面速查](../interview/README.md)。要点就一句：**维持，而不是突击。** 每天一小时，
比周末十小时有用得多，因为这些东西靠的是手感。

### 3. 人

推荐、老同事、一起做过项目的人、在网上认真回答过你问题的人。不是让你去"混人脉"，
是说：**别人愿不愿意为你说一句话，很多时候比你多刷五十道题管用。**

这也是我说[技能只占 30%](README.md#还有一点我自己的看法) 的意思。你平时怎么和人相处，
在找工作的时候会一次性结算。

## 三、那些黑话

第一次找工作的时候，我被这些词搞晕过。都是行业通用的说法，不是哪一家的流程：

| 词 | 大概是什么 |
| --- | --- |
| OA | Online Assessment，线上做题，通常是自动判分 |
| recruiter screen | 和招聘的人聊，确认方向、时间线、签证这些 |
| phone screen / technical screen | 第一轮技术面，通常一小时 |
| onsite / loop | 一串连着的面试，现在多数还是线上 |
| BQ / behavioral | 行为面，问你过去怎么处理具体情况 |
| system design | 系统设计面，看你怎么权衡，不是看你背了多少 |
| HC | Hiring Committee，有些公司由委员会而不是面试官决定是否发 offer |
| team match | 过了技术面之后再和具体团队配对，有的公司先配对后面试 |
| level | 职级。同样是"给 offer"，级别不同差别很大 |
| base / bonus / RSU / sign-on | 底薪 / 奖金 / 股票 / 签字费，offer 是这几块加起来的 |
| refresh | 入职后每年追加的股票 |
| return offer | 实习结束时给的全职 offer |
| referral | 内推。作用是让简历被人看到，不是让你跳过面试 |
| ATS | 公司用来筛简历的系统，所以简历别做太花，机器读不了 |

## 四、心态：这部分比技术难

**拒信是常态，不是判决。** 同一个人，这家挂了那家过了，很正常。招聘这件事噪声极大：
面试官当天的状态、head count 还剩几个、你前面那个候选人多强，这些你都控制不了。

**别把 offer 当成对你这个人的评分。** 它衡量的是"在这个时间点、这一场面试里、对这个岗位，
你表现出来的匹配度"。这句话很长，但每一个限定词都重要。

**挂了就复盘，但只复盘能改的。** 哪道题卡住了、哪个概念讲不清、哪段经历讲得散——这些下次能改。
"面试官不喜欢我"——改不了，别在上面耗。我自己的复盘长这样：[一次 MLE 面试的复盘](one-interview.md)。

**给自己设个止损。** 连着面砸了三场，不是更用力，是先停两天。这行的面试很耗，
状态差的时候硬上，只会把本来能过的也面砸。

**允许自己中途改主意。** 准备了三个月发现不喜欢这个方向，那就是三个月买来的信息，不是浪费。

## 五、一个粗略的节奏

如果你还有两三个月：

1. **第一周**：把简历上每条经历写成故事，自己录音讲一遍，听回放。难受，但有用。
2. **前一个月**：基本功每天一小时，同时开始投——不要等"准备好了"再投，那天不会来。
3. **面试期间**：每场面完当天写复盘，趁记得。一周回头看一次，找重复出现的问题。
4. **一直**：和人聊。聊行业、聊组、聊他们在做什么。这件事的回报最慢，也最长久。

最后一句：这一路会很难受，是真的难受，但它只是一段时间。我也是这么过来的 :)
