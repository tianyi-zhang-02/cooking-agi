# 求职：先读这一页

**中文** · [English](README.en.md)

> 阅读时间：约 2 分钟 · 最近审阅：2026-09

这里记录**找工作的经历、心态和选择**：怎么安排准备、遇到挫折时怎么调整，以及我后来改变了哪些想法。主要围绕我熟悉的 ML / research 方向，不是一份适用于所有人的求职攻略。读之前，有几件事想先说明：

> **先读这个**
>
> 1. **很多内容有时效性。** 招聘市场变得很快，你读到的时候，这里写的东西或许已经不适用了。每一页顶部都有“最近审阅”的日期，可以结合日期判断是否还适合自己。
> 2. **我是留学生。** 签证和工作许可会影响我的选择，有美国绿卡或公民身份的同学，情况可能不同。
> 3. **这里不写面试题，也不写任何一家公司特定的面试流程。** 只写我自己的时间线、踩过的坑，和对岗位的认知。

## 还有一点我自己的看法

对我来说，找工作不只是展示技术能力，也是在看彼此能不能一起做事。怎么沟通、怎么对待合作中的分歧、答应的事情能不能做到，这些同样重要。

我自己也还在学。希望最后不只是找到合适的工作，也能成为一个让人愿意合作、值得信任的人。
