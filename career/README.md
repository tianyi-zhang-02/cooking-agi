# 求职：先读这一页

**中文** · [English](README.en.md)

> 阅读时间：约 2 分钟 · 最近审阅：2026-10

大学那几年，我大部分时间都在做研究。去年开始找实习时，对公司里的岗位其实没什么概念。想去业界，是因为想看看自己做的东西能不能真的被人用上。但从有这个想法，到知道该投什么、该准备什么，中间绕了不少路。

这里就记这些。准备得不好的地方、面完才想明白的话，还有找着找着改变的主意，都放在一起。我现在也还在找工作，没到能总结出一套“上岸方法”的时候。

如果你也在准备 ML 方向的实习或 new grad，可以挑和自己有关的看。能少花一点到处找资料的时间，或者发现“原来别人也卡在这里”，就挺好了 :)

## 从哪篇看起

### 想看我怎么走过来的

- [25-26 intern 求职](journey.md)：一开始什么都投，后来为什么收窄到 MLE / Research Engineer。
- [26-27 new grad 求职 🚧](new-grad-2026-2027.md)：这一轮还在找，有进展再慢慢补。
- [一次 MLE 面试的复盘](one-interview.md)：项目聊得还行，基础知识没答好，也发现用中文讲技术需要单独练。

### 想聊准备和心态

- [到底要准备什么](prepare.md)：如果再准备一次，我会先把时间花在哪些地方。
- [它只是人生的一部分](not-binary.md)：面试该认真准备，但没必要面挂一次，就把自己全盘否定。
- [别让指标锁死你](metrics.md)：刷了多少题、投了多少份，和准备得怎么样，并不是一回事。

### 想直接练技术

Python、LeetCode、ML 基础和系统设计放在[学习笔记](../learn/README.md)。这里留给经历和想法，不把两边混在一起。

## 读的时候，知道我的情况就好

我的经历主要在 ML 和研究，SDE、前后端这些方向，我不是很好的参考来源。我也是留学生，工作许可、地点和时间线都会影响选择，不能直接套到每个人身上。

旧经历会留着原来的招聘季。市场和各家的安排会变，某一轮的体会就当某一轮看。这里不放具体面试题或未公开流程，也不会把一次面试写成一家公司的全貌。

有讲得不清楚的地方，欢迎提 issue。你走过的路可能和我不一样，也许正好能补上我没看到的部分。
