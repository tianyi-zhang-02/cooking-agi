我在[心路历程](journey.md)里踩的第三个坑是“不了解岗位”。它带来的直接后果是：我以为自己在准备“找工作”，实际上是在同时准备好几个互不相干的考试。

## 同时准备几个岗位，有多少能复用？

点选你打算同时投的岗位，看要准备的方向有多少、其中又有多少是能复用的。

把五个都点上，再只留一个，对比一下那条进度条。这就是“海投”的真实成本：不是投简历花的时间，而是**准备没法复利**。

## 每个岗位大致在考什么

| 岗位 | 主要方向 |
| --- | --- |
| Data Engineer | SQL、数据建模、ETL 与数据管道、分布式系统基础、数据结构与算法 |
| Data Scientist | 统计推断、A/B testing、product sense、SQL、概率、ML 基础 |
| MLE | ML 基础、深度学习与 LLM、ML system design、数据结构与算法、概率、线性代数 |
| SDE | 数据结构与算法、system design、面向对象与工程实践、分布式系统基础 |
| Quant Researcher | 概率、期望与心算、逻辑推理题、统计推断、线性代数 |
