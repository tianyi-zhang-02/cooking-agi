# 工程实践

**中文** · [English](README.en.md)

学习笔记里讲一个方法怎么工作，这里记录把它用起来时遇到的问题：从哪里发现不对，为什么选择这样改，以及怎么知道改动有效。

内容还在整理，后面会慢慢补；只写有公开代码、资料或可复现实验支持的内容，不放公司内部项目。

## 一篇实践笔记会讲什么

1. **遇到了什么问题？** 先交代任务、约束和观察到的现象，区分已经验证的事实和猜测。
2. **为什么这样做？** 比较可选方案，说明为什么选这一种，又放弃了什么。
3. **具体怎么实现？** 结合公开代码，看数据流、接口和关键细节。
4. **怎么验证？** 记录复现方法、测试和测量条件，也写清还没验证的部分。

不一定要有很大的性能提升才值得记录。一个定位清楚的 bug、一次排除错误假设的实验，或者一个没采用的方案，都可能帮到下一个遇到类似问题的人。

## 需要补基础时

- [Post-training](../05-post-training/)：先弄清训练目标，再看框架如何实现。
- [评估](../07-evaluation/)：实验该怎么设计，指标能说明什么、不能说明什么。
- [系统与多模态](../06-systems/)：请求经过哪些组件，以及怎么观察中间过程。

教学用的小实验仍放在[学习笔记](../00-foundations/)里。这边重点是一个具体问题的处理过程，两边通过链接互相补充，不重复放同一篇文章。

## 也欢迎你的实践记录

如果你有公开项目里的调试经历、实验或实现，欢迎分享。写清背景、过程和依据就好，不用把它包装成一套完整方案。参与方式见[贡献指南](../CONTRIBUTING.md)。

请勿提交公司内部资料、私有数据或其他敏感信息；已有的私有笔记不会因为新增这个板块而公开。
