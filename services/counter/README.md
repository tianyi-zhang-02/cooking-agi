# 匿名计数服务 · Anonymous counters

**中文** · [English](#english)

给站点提供两样数字，都跑在 Cloudflare 免费额度上：

- **此刻在学 / 今天在学**：学习小伙伴显示的人数。
- **笔记的阅读与收藏**：每篇笔记底部的计数，协议和含义见 [`site/tools/note-metrics.md`](../../site/tools/note-metrics.md)（读者主动开启后才会上报）。

主站仍然放在 GitHub Pages，这个服务只是一个旁边的接口；它挂了，网站和本地收藏照常能用。

## 隐私

- **不存 IP，不放 cookie。** 访客身份是「IP + 浏览器标识」加一个盐做的哈希；盐每个 UTC 日随机生成一次，第二天就被换掉，所以同一个人隔天无法被关联。
- 前一天的访客哈希和阅读去重记录在新的一天开始时删除。
- 笔记计数用的随机令牌由页面生成、只在读者开启统计后发送；服务端先用密钥（`TOKEN_PEPPER`）加盐哈希再存，原始令牌不落盘。
- 代码不写任何请求日志，`wrangler.toml` 也关掉了 Cloudflare 的日志采集。
- 浏览器开了「不跟踪」（DNT / GPC）时，页面只读人数，不发心跳。

## 防滥用

- 只接受站点自己的页面写入：`POST` 必须带白名单里的 `Origin`（`ALLOWED_ORIGINS`），跨域许可也只给这些来源。
- 笔记 ID 必须在公开目录（`CATALOG_URL`）里；事件格式必须完全一致，请求体最多 1 KB。
- 每个访客限流：心跳每分钟 6 次、读取 120 次、写入 30 次，超出返回 429。
- 匿名标识挡得住随手重复点，挡不住刻意伪造大量身份的机器人；数字是近似值，页面也是这么写的。

## 额度与费用

全部在 Workers 免费计划内，**0 元**：每天 10 万次请求，Durable Object 每天写 10 万行。每位读者开着页面时每 2 分钟一次心跳，大约够每天三千个「读者·小时」。超出后当天的请求会失败，页面会自动隐藏人数，第二天 UTC 零点恢复。真到那个量，再考虑每月 5 美元的付费计划。

## 部署（需要你本人操作）

1. 注册 Cloudflare 账号（免费）：<https://dash.cloudflare.com/sign-up>。
2. 在这个目录登录（浏览器里点授权）：

   ```bash
   cd services/counter && npx wrangler@4 login
   ```

3. 设置令牌密钥（粘贴下面命令生成的随机串，自己不用记）：

   ```bash
   openssl rand -hex 32
   ```

   ```bash
   npx wrangler@4 secret put TOKEN_PEPPER
   ```

4. 部署，记下输出的地址（形如 `https://cooking-agi-counter.<你的子域>.workers.dev`）：

   ```bash
   npx wrangler@4 deploy
   ```

5. 把 `https://…workers.dev/api/note-metrics/` 写进 `site/static/note-metrics-config.json` 的 `endpoint`。这一步发个 PR 就行：学习小伙伴的人数和笔记计数会同时打开，页面的 CSP 也会自动放行这个地址。

本地测试：`node --test test/`（用 Python 自带的 SQLite 跑真实的 SQL）。

# Anonymous counters

Two kinds of numbers for the site, on Cloudflare's free tier:

- **Studying now / today**, shown by the study buddy.
- **Reads and saves per note**, as specified in [`site/tools/note-metrics.md`](../../site/tools/note-metrics.md) (sent only after a reader opts in).

The site stays on GitHub Pages; this is a side endpoint. If it is down, the site and local bookmarks keep working.

## Privacy

- **No stored IPs, no cookies.** A visitor is a hash of IP + user agent with a salt that is random for each UTC day and replaced the next, so nobody can be linked across days.
- Yesterday's visitor hashes and read-deduplication keys are deleted when a new day starts.
- Note tokens are generated by the page and sent only after opt-in; the service hashes them with a secret (`TOKEN_PEPPER`) before storing. Raw tokens are never written.
- The code logs nothing, and `wrangler.toml` turns Cloudflare's log collection off.
- With Do Not Track / Global Privacy Control, pages only read the counts and send no heartbeat.

## Abuse controls

- Writes are accepted only from the site's pages: a `POST` must carry an allowed `Origin` (`ALLOWED_ORIGINS`), and CORS grants go only to those origins.
- Note IDs must be in the public catalog (`CATALOG_URL`); events must match exactly; bodies are capped at 1 KB.
- Per-visitor limits: 6 heartbeats, 120 reads and 30 writes a minute; beyond that, 429.
- Anonymous identifiers stop casual repeats, not a determined bot inventing identities. Counts are approximate, and the pages say so.

## Limits and cost

Everything fits the Workers Free plan, **$0**: 100,000 requests a day and 100,000 Durable Object rows written a day. One heartbeat every two minutes per open page is roughly 3,000 reader-hours a day. Beyond that, requests fail for the rest of the UTC day and pages simply hide the counts. At that point, consider the $5/month paid plan.

## Deploy (the owner does this)

1. Create a free Cloudflare account: <https://dash.cloudflare.com/sign-up>.
2. Log in from this directory (approve in the browser): `cd services/counter && npx wrangler@4 login`
3. Set the token secret (paste a random string, e.g. from `openssl rand -hex 32`): `npx wrangler@4 secret put TOKEN_PEPPER`
4. Deploy and note the URL (`https://cooking-agi-counter.<subdomain>.workers.dev`): `npx wrangler@4 deploy`
5. Put `https://…workers.dev/api/note-metrics/` in `site/static/note-metrics-config.json` as `endpoint`, in a PR. That turns on both the buddy's counts and the note counts; the page CSP picks up the origin automatically.

Local tests: `node --test test/` (real SQL on Python's built-in SQLite).
