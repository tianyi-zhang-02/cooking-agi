# 前沿：先问清楚指的是哪件事

**中文** · [English](README.en.md)

> 阅读时间：约 3 分钟 · 最近审阅：2026-10

“世界模型”有时指 RL 中预测下一步状态的模型，有时指能用键盘控制的交互式视频。“自我改进”也类似：用模型生成的数据继续训练，和用 AI 帮研究员写代码，是两件不同的事。

这里整理这些正在发展的方向：先解释方法怎么工作，再看论文和公开系统做到了什么，还有哪些问题没有解决。

## 为什么单独放一块

基础章节主要解释已经广泛使用的方法，这里则更关注新方法和仍有争议的问题。读一项新结果时，我们会看它测了什么、实验条件是什么，也会区分实测结果、作者的解释和对未来的预测。每篇标有“最近审阅”日期，计划每 6 个月复核一次。

收进来的方向要满足两点：已经在改变实际的系统设计，并且有可以核对的公开证据。只是最近很热的词，不单独开篇。

每个系列会区分已有证据支持的结论、仍待验证的做法，以及值得关注的后续实验。涉及新系统和性能数字时，会注明日期、来源和实验条件；公司自己报告的数字标为“自报”，方便回到原文核对。

| 你读到的说法 | 先问什么 |
| --- | --- |
| “某某是一个世界模型” | 它预测什么、在什么空间里预测、以什么为条件、拿来做什么？ |
| “AI 在改进它自己” | 改的是哪个对象，谁来决定改动，靠什么信号接受改动？ |
| “测到了 N 倍加速” | 谁测的、用什么单位、有多少人工介入、算力是否同时增长？ |

## 六个系列

1. [世界模型：这个词现在指哪几种东西](world-models/README.md)。从 Dreamer 在想象里训练策略，到 JEPA 预测表示，再到能交互的视频、给机器人当评测器，最后看它们是否真的懂物理。
2. [递归自我改进（RSI）：先问改的是什么](self-improvement/README.md)。区分改权重、改代码、加速研发和自产数据，看验证器为什么决定上限，以及“AI 加速 AI”现在怎么测量。
3. [推理模型与测试时计算：多想一会儿，什么时候有用](test-time-compute/README.md)。多采样投票、验证器、长思维链怎样训练出来，以及在同等算力下怎么比较。
4. [用强化学习训练 agent（agentic RL）：从一问一答到多步任务](agentic-rl/README.md)。环境和奖励从哪里来、会怎样被钻空子，多步回合里梯度落在哪些 token 上。
5. [机制可解释性：打开模型看它怎么算](interpretability/README.md)。探针、叠加、稀疏自编码器和电路，各自能说明什么、说明不了什么。
6. [扩散语言模型（dLLM）：不从左到右，整块去噪](diffusion-lm/README.md)。掩码扩散在训练什么、和 BERT 的 MLM 是什么关系，以及并行解码为什么不会自动变快。
