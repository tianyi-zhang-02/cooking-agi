# 更新与阅读记录 {#updates}

**中文** · [English](updates.en.md)

这页说明网站怎样更新，以及你的收藏和阅读记录存在哪里。接下来想做什么，放在[路线图](roadmap.md)。

## 网站怎样更新 {#how}

网站不打版本号，也不等攒够一批再发布：改动合并进主分支、部署成功后就上线。每次合并改了什么，按日期记在首页的[更新记录](../README.zh.md#changelog)里；某篇文章的具体修改，可以查看页尾的源文件和仓库历史。

原先计划的「v1.0.0 · 面试准备」不再发布，已经做好的功能照常可用。

## 收藏和阅读记录 {#records}

- **收藏**：笔记标题下点「收藏本页」，在右上角「我的阅读」里找到。
- **阅读记录**：「我的阅读」记下今天读了哪些笔记、读了几次，也记住每篇读到了哪里。
- **备份**：收藏、阅读记录和阅读位置共用一份 JSON 备份；导入是合并，同一条记录保留较新的一份。

这些记录只存在当前浏览器里，不需要注册，也不会上传。网站更新不会主动清空同一浏览器、同一站点地址里的记录；备份格式单独管理，旧备份仍然能导入。

但这不是云同步。换设备、换浏览器、换站点地址，或清理网站数据时，需要自己导出再导入。多个标签同时改同一条记录，不保证都能保存下来。**私人备份不要上传到 issue 或仓库。**

## 已知限制 {#limits}

- 读完或收藏一篇，不等于掌握了内容；没有自动评分或能力预测。
- 没有账号、云同步、离线缓存或付费服务。浏览器存储不可用时，请及时导出。
- 自动检查和浏览器抽查，不等于每个技术结论都已独立审过，也不等于做过 GPU 或真机实验。
