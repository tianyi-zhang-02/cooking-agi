## 初衷

这里记录我学习现代 AI 系统时的理解，并尽量整理成别人也能直接拿来学的样子。

我想弄明白的，不只是“怎样训练一个更大的模型”，而是怎样把数据、记忆、搜索、工具、反馈和评估放在一起，做出一个**真的会理解人、会找信息、也会越用越好的 AI 系统**。

所以每一篇都先讲它解决什么问题、为什么需要它，用一个最简单的例子讲清楚，再进入技术细节，最后说它依赖什么假设、会在哪里失败。写法是 modern-first：从今天的 LLM 系统出发，历史只在能解释现在的设计时才讲。

这是持续更新的个人理解，不是最终答案。
